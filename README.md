# 🚀 CareerBoost AI

### AI-Powered AI Resume Assistant and Builder

CareerBoost AI is an intelligent resume analysis and resume-building platform developed using Python, Streamlit, NLP, and SQLite. The system helps users improve their resumes through ATS analysis, skill extraction, keyword optimization, and AI-powered recommendations.

---

# 📌 Features

## 🔍 Resume Analysis
- ATS Compatibility Score
- Resume Keyword Analysis
- Skills Extraction
- Resume Strength & Weakness Detection
- Role-Based Recommendations
- AI Resume Feedback

## 📝 Resume Builder
- Professional Resume Templates
- Resume Section Customization
- PDF Resume Generation
- Modern Resume Designs

## 📊 Dashboard & Analytics
- Resume Analytics
- Skills Tracking
- Resume Score Visualization
- Analysis History

## 🎯 Job Assistance
- Job Search Integration
- Job Recommendations
- Career Insights
